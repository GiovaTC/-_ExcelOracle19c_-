## Programa Java con interfaz gráfica para generar y visualizar archivos Excel utilizando Oracle 19c

## 1. Descripción del proyecto

Este proyecto consiste en una aplicación desarrollada en Java utilizando IntelliJ IDEA, con una interfaz gráfica
que permite consultar información almacenada en Oracle Database 19c, generar archivos Excel y visualizar su contenido directamente en la interfaz.

La aplicación utiliza:

- Java 21.
- IntelliJ IDEA.
- Oracle Database 19c.
- JDBC para la conexión con Oracle.
- Apache POI para generar y leer archivos Excel.
- Java Swing para la interfaz gráfica.
- Maven para administrar las dependencias.

## 2. Funcionalidades

El programa permite:

1. Consultar registros almacenados en Oracle 19c.
2. Mostrar los registros en una tabla gráfica.
3. Generar archivos Excel en formato `.xlsx`.
4. Seleccionar la ubicación donde se guardará el archivo.
5. Abrir archivos Excel existentes.
6. Visualizar los datos de Excel en la interfaz gráfica.
7. Limpiar la tabla de resultados.

## 5. Configuración de Oracle 19c

### 5.1 Crear la tabla

Ejecutar el siguiente script en Oracle SQL Developer:

```sql
CREATE TABLE REGISTROS_EXCEL (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NOMBRE VARCHAR2(100) NOT NULL,
    VALOR NUMBER(12,2),
    FECHA_REGISTRO DATE DEFAULT SYSDATE
);
```

## 7. Código completo de Main.java

Ruta:

`src/main/java/com/exceloracle/Main.java`

```java
package com.exceloracle;

import org.apache.poi.ss.usermodel.*;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;

import javax.swing.*;
import javax.swing.table.DefaultTableModel;
import java.awt.*;
import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.sql.*;
import java.text.SimpleDateFormat;

public class Main extends JFrame {

    private static final String URL =
            "jdbc:oracle:thin:@//localhost:1521/orcl";

    private static final String USUARIO = "system";

    private static final String CLAVE = "TU_CLAVE_ORACLE";

    private JTable tabla;

    private DefaultTableModel modelo;

    public Main() {

        setTitle("Excel - Oracle 19c");

        setSize(900, 550);

        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        setLocationRelativeTo(null);

        inicializarInterfaz();
    }

    // INTERFAZ GRÁFICA
    private void inicializarInterfaz() {

        JPanel panelPrincipal =
                new JPanel(new BorderLayout(10, 10));

        panelPrincipal.setBorder(
                BorderFactory.createEmptyBorder(
                        15, 15, 15, 15
                )
        );

        JLabel titulo = new JLabel(
                "GENERADOR DE ARCHIVOS EXCEL - ORACLE 19C",
                SwingConstants.CENTER
        );

        titulo.setFont(
                new Font("Arial", Font.BOLD, 20)
        );

        panelPrincipal.add(
                titulo,
                BorderLayout.NORTH
        );

        // TABLA
        modelo = new DefaultTableModel(
                new String[]{
                        "ID",
                        "NOMBRE",
                        "VALOR",
                        "FECHA"
                },
                0
        );

        tabla = new JTable(modelo);

        tabla.setRowHeight(25);

        JScrollPane scroll = new JScrollPane(tabla);

        panelPrincipal.add(
                scroll,
                BorderLayout.CENTER
        );

        // BOTONES
        JPanel panelBotones = new JPanel(
                new FlowLayout(
                        FlowLayout.CENTER,
                        10,
                        10
                )
        );

        JButton btnConsultar =
                new JButton("Consultar Oracle");

        JButton btnGenerar =
                new JButton("Generar Excel");

        JButton btnAbrir =
                new JButton("Abrir Excel");

        JButton btnLimpiar =
                new JButton("Limpiar");

        panelBotones.add(btnConsultar);

        panelBotones.add(btnGenerar);

        panelBotones.add(btnAbrir);

        panelBotones.add(btnLimpiar);

        panelPrincipal.add(
                panelBotones,
                BorderLayout.SOUTH
        );

        add(panelPrincipal);

        // EVENTOS
        btnConsultar.addActionListener(
                e -> consultarOracle()
        );

        btnGenerar.addActionListener(
                e -> generarExcel()
        );

        btnAbrir.addActionListener(
                e -> abrirExcel()
        );

        btnLimpiar.addActionListener(
                e -> limpiarTabla()
        );
    }

    // CONEXIÓN A ORACLE 19C
    private Connection conectarOracle()
            throws SQLException {

        return DriverManager.getConnection(
                URL,
                USUARIO,
                CLAVE
        );
    }

    // CONSULTAR REGISTROS DE ORACLE
    private void consultarOracle() {

        modelo.setRowCount(0);

        String sql = """
                SELECT ID,
                       NOMBRE,
                       VALOR,
                       FECHA_REGISTRO
                FROM REGISTROS_EXCEL
                ORDER BY ID
                """;

        try (
                Connection conexion =
                        conectarOracle();

                PreparedStatement ps =
                        conexion.prepareStatement(sql);

                ResultSet rs =
                        ps.executeQuery()
        ) {

            SimpleDateFormat formato =
                    new SimpleDateFormat("yyyy-MM-dd");

            while (rs.next()) {

                Object[] fila = {

                        rs.getInt("ID"),

                        rs.getString("NOMBRE"),

                        rs.getBigDecimal("VALOR"),

                        formato.format(
                                rs.getDate(
                                        "FECHA_REGISTRO"
                                )
                        )
                };

                modelo.addRow(fila);
            }

            JOptionPane.showMessageDialog(
                    this,
                    "Consulta realizada correctamente.\n"
                            + "Registros: "
                            + modelo.getRowCount()
            );

        } catch (SQLException ex) {

            mostrarError(
                    "Error al consultar Oracle:\n"
                            + ex.getMessage()
            );
        }
    }

    // GENERAR ARCHIVO EXCEL
    private void generarExcel() {

        if (modelo.getRowCount() == 0) {

            JOptionPane.showMessageDialog(
                    this,
                    "Primero consulta los registros de Oracle."
            );

            return;
        }

        JFileChooser selector =
                new JFileChooser();

        selector.setDialogTitle(
                "Guardar archivo Excel"
        );

        selector.setSelectedFile(
                new File("ReporteOracle19c.xlsx")
        );

        int resultado =
                selector.showSaveDialog(this);

        if (resultado !=
                JFileChooser.APPROVE_OPTION) {

            return;
        }

        File archivo =
                selector.getSelectedFile();

        // Asegurar extensión XLSX
        if (!archivo.getName()
                .toLowerCase()
                .endsWith(".xlsx")) {

            archivo = new File(
                    archivo.getAbsolutePath()
                            + ".xlsx"
            );
        }

        try (Workbook libro =
                     new XSSFWorkbook()) {

            Sheet hoja =
                    libro.createSheet(
                            "Reporte Oracle"
                    );

            // ESTILO DEL ENCABEZADO
            CellStyle estiloEncabezado =
                    libro.createCellStyle();

            Font fuente =
                    libro.createFont();

            fuente.setBold(true);

            fuente.setColor(
                    IndexedColors.WHITE.getIndex()
            );

            estiloEncabezado.setFont(fuente);

            estiloEncabezado
                    .setFillForegroundColor(
                            IndexedColors.DARK_BLUE
                                    .getIndex()
                    );

            estiloEncabez
                    .setFillPattern(
                            FillPatternType
                                    .SOLID_FOREGROUND
                    );

            // CREAR ENCABEZADOS
            Row encabezado =
                    hoja.createRow(0);

            for (
                    int columna = 0;
                    columna < modelo.getColumnCount();
                    columna++
            ) {

                Cell celda =
                        encabezado.createCell(
                                columna
                        );

                celda.setCellValue(
                        modelo.getColumnName(
                                columna
                        )
                );

                celda.setCellStyle(
                        estiloEncabezado
                );
            }

            // CREAR FILAS
            for (
                    int fila = 0;
                    fila < modelo.getRowCount();
                    fila++
            ) {

                Row filaExcel =
                        hoja.createRow(
                                fila + 1
                        );

                for (
                        int columna = 0;
                        columna < modelo.getColumnCount();
                        columna++
                ) {

                    Cell celda =
                            filaExcel.createCell(
                                    columna
                            );

                    Object valor =
                            modelo.getValueAt(
                                    fila,
                                    columna
                            );

                    celda.setCellValue(
                            valor == null
                                    ? ""
                                    : valor.toString()
                    );
                }
            }

            // AJUSTAR ANCHO DE COLUMNAS
            for (
                    int columna = 0;
                    columna < modelo.getColumnCount();
                    columna++
            ) {

                hoja.autoSizeColumn(
                        columna
                );
            }

            // GUARDAR ARCHIVO
            try (
                    FileOutputStream salida =
                            new FileOutputStream(
                                    archivo
                            )
            ) {

                libro.write(salida);
            }

            JOptionPane.showMessageDialog(
                    this,
                    "Archivo Excel generado correctamente:\n"
                            + archivo.getAbsolutePath()
            );

            // VISUALIZAR EL ARCHIVO
            cargarExcelEnTabla(
                    archivo
            );

        } catch (Exception ex) {

            mostrarError(
                    "Error al generar Excel:\n"
                            + ex.getMessage()
            );
        }
    }

    // ABRIR ARCHIVO EXCEL
    private void abrirExcel() {

        JFileChooser selector =
                new JFileChooser();

        selector.setDialogTitle(
                "Seleccionar archivo Excel"
        );

        int resultado =
                selector.showOpenDialog(this);

        if (resultado !=
                JFileChooser.APPROVE_OPTION) {

            return;
        }

        File archivo =
                selector.getSelectedFile();

        cargarExcelEnTabla(
                archivo
        );
    }

    // LEER EXCEL Y MOSTRAR SU CONTENIDO
    private void cargarExcelEnTabla(
            File archivo
    ) {

        try (
                FileInputStream entrada =
                        new FileInputStream(
                                archivo
                        );

                Workbook libro =
                        WorkbookFactory.create(
                                entrada
                        )
        ) {

            Sheet hoja =
                    libro.getSheetAt(0);

            modelo.setRowCount(0);

            modelo.setColumnCount(0);

            Row encabezado =
                    hoja.getRow(0);

            if (encabezado == null) {

                throw new Exception(
                        "El archivo Excel "
                                + "no tiene encabezados."
                );
            }

            // LEER ENCABEZADOS
            for (
                    int columna = 0;
                    columna < encabezado
                            .getLastCellNum();
                    columna++
            ) {

                Cell celda =
                        encabezado.getCell(
                                columna
                        );

                modelo.addColumn(
                        obtenerValorCelda(
                                celda
                        )
                );
            }

            // LEER FILAS
            for (
                    int fila = 1;
                    fila <= hoja.getLastRowNum();
                    fila++
            ) {

                Row filaExcel =
                        hoja.getRow(fila);

                if (filaExcel == null) {

                    continue;
                }

                Object[] datos =
                        new Object[
                                modelo.getColumnCount()
                        ];

                for (
                        int columna = 0;
                        columna < modelo
                                .getColumnCount();
                        columna++
                ) {

                    datos[columna] =
                            obtenerValorCelda(
                                    filaExcel.getCell(
                                            columna
                                    )
                            );
                }

                modelo.addRow(datos);
            }

            JOptionPane.showMessageDialog(
                    this,
                    "Archivo Excel cargado "
                            + "en la interfaz."
            );

        } catch (Exception ex) {

            mostrarError(
                    "Error al abrir Excel:\n"
                            + ex.getMessage()
            );
        }
    }

    // OBTENER VALOR DE UNA CELDA
    private String obtenerValorCelda(
            Cell celda
    ) {

        if (celda == null) {

            return "";
        }

        DataFormatter formato =
                new DataFormatter();

        return formato.formatCellValue(
                celda
        );
    }

    // LIMPIAR TABLA
    private void limpiarTabla() {

        modelo.setRowCount(0);
    }

    // MOSTRAR ERRORES
    private void mostrarError(
            String mensaje
    ) {

        JOptionPane.showMessageDialog(
                this,
                mensaje,
                "Error",
                JOptionPane.ERROR_MESSAGE
        );
    }

    // INICIO DEL PROGRAMA
    public static void main(
            String[] args
    ) {

        SwingUtilities.invokeLater(
                () -> {

                    Main ventana =
                            new Main();

                    ventana.setVisible(
                            true
                    );
                }
        );
    }
}
```

`com.exceloracle`

Modificar las credenciales en `Main.java`:

```java
private static final String URL =
        "jdbc:oracle:thin:@//localhost:1521/orcl";

        "system";

        "TU_CLAVE_ORACLE";
```

## 9. Uso del programa

### Consultar Oracle

Presionar el botón:

`Consultar Oracle`

El programa ejecutará una consulta SQL y mostrará los registros de Oracle 19c en la tabla de la interfaz.

### Generar Excel

Presionar:

`Generar Excel`

Seleccionar la ruta y el nombre del archivo.

Ejemplo:

```text
ReporteOracle19c.xlsx
```

El archivo tendrá los encabezados:

```text
ID | NOMBRE | VALOR | FECHA
```

Después de generar el Excel, el programa cargará su contenido en la tabla gráfica.

### Abrir Excel

Presionar:

`Abrir Excel`

Seleccionar un archivo `.xlsx`.

El programa leerá el contenido y mostrará sus datos en la interfaz.

### Limpiar

Presionar:

`Limpiar`

Se eliminarán las filas de la tabla gráfica.
